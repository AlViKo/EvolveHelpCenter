This guide covers how to register and log into the Evolve platform using the web version and the mobile app.

## How to Register on the Platform

If any of your colleagues already work in the system, the company account has already been created. Ask your colleagues or administrator to add you as one of the platform users with your email address — you will then receive an invitation email.

Follow the link in the email and log in, or simply log in to the platform using your corporate email address.

## Login to the Site Using Email

![Evolve platform login screen](/images/auth-login-screen.png)

### Step 1 — Open the authorization page

Go to [https://dashboard.evolveplatform.ai](https://dashboard.evolveplatform.ai)

### Step 2 — Enter your email address

Use the same address to which you received your invitation to the system.

### Step 3 — Receive and enter the code

The system will send a 6-digit code to your email. Enter it in the authorization field. The code will arrive within 1–5 minutes.

Done! After entering the code, you will be automatically logged in.

## Mobile Application

You can log in to the platform via the mobile app using your username and password.

However, it is important to understand:

**The admin panel is not available in the mobile app.** You will not be able to create or edit courses, manage users, or create tracks and events. These features are available only in the web version via browser.

**In the mobile version you can:**

- Take courses
- Use the knowledge base
- Track your progress

If you are an administrator, use the web version to manage content and users. The mobile app is suitable for users undergoing training.

## Installing the Mobile Application

![Scan the QR code to download the Evolve mobile app](/images/auth-mobile-app-qr.png)

Download the app by scanning the QR code above, or find the download links in the **Download app** section of the platform's left-hand menu.

## Login to the Mobile App

1. Open the app and select **Login with email**.
2. Enter your email address — use the same address to which you received your invitation.
3. The system will send a 6-digit code to your email. Enter it in the application (the code will arrive within 1–5 minutes).

Done! After entering the code, you will be automatically logged in.

## FAQ: Platform Access

### How to access the platform?

Open [https://dashboard.evolveplatform.ai](https://dashboard.evolveplatform.ai) → enter your email → receive and enter the 6-digit code from the email → you are logged in.

### How to download the app?

In the web version of the platform, open the left navigation menu and select **Download the app**. Scan the QR code to proceed to installation.

### Is it possible to take a course from a mobile device?

Yes, via the mobile app or via the browser on your device.

### What features are available in the app?

The admin panel is not available in the mobile app. You will not be able to create or edit courses, manage users, or create tracks and events. These features are available only in the web version through the browser. In the mobile version you can take courses, use the knowledge base, and track your progress.

### How do I update my personal information?

In the left menu, go to **Profile Settings**, make your changes, and save.

### How to change the interface language?

In the left menu at the very bottom (in the settings section), click on the flag icon and select the desired language from the list. The interface will switch immediately — no need to reload the page.

### What should I do if I don't receive the login code?

1. Check your **Spam** and **Promotions** folders.
2. If you don't receive the email, try again in 5 minutes.
3. If the problem persists, contact support at support@evolveplatform.ai

### What to do if you don't receive any emails from the platform?

This may affect all notifications — login codes, course assignment emails, training readiness notifications, and other system messages.

1. Check the **Spam** and **Promotions** folders.
2. If there is no email, try again in 5 minutes.
3. If the problem persists, it may be that your corporate email server or rules are blocking external emails (especially relevant for large companies).

In this case, inform your colleague and report that emails from the platform are not arriving, or send an email to support@evolveplatform.ai. It is very important to solve this problem before the launch of training so that users can receive all notifications and login codes.

### Where should I go if I have problems with the platform?

Write to support at support@evolveplatform.ai, use the support chat icon in the bottom right corner of the platform, or contact your account manager.
