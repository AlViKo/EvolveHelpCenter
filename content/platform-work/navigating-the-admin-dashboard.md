# Navigating the Admin Dashboard

The Evolve admin dashboard is your central hub for managing courses, monitoring learner engagement, and configuring platform settings. This overview walks you through the main areas of the dashboard so you can find what you need quickly.

## Dashboard Layout

When you log in as an admin, you land on the **Home** screen, which is divided into three main sections:

- **Top Navigation Bar**: Contains the search bar, notification bell, and your profile menu.
- **Left Sidebar**: Provides access to all major platform sections.
- **Main Content Area**: Displays widgets, reports, and page content based on your current selection.

## Left Sidebar Sections

The sidebar organizes the platform into the following areas:

1. **Home** -- Overview widgets showing key metrics at a glance.
2. **Courses** -- Access the course library, course builder, and content management tools.
3. **Users & Teams** -- View the user directory, manage teams, and configure roles.
4. **Reports** -- Generate and export reports on learner progress, course completion rates, and engagement.
5. **Learning Paths** -- Create structured sequences of courses for different roles or departments.
6. **Settings** -- Configure authentication, branding, integrations, and billing.

## Home Screen Widgets

The Home screen displays real-time data through configurable widgets:

- **Active Learners**: The number of users who logged in during the past 7 days.
- **Course Completion Rate**: A percentage showing how many assigned courses have been completed across your organization.
- **Recent Activity Feed**: A timeline of the latest actions, including new enrollments, completions, and content updates.
- **Upcoming Deadlines**: A list of courses with approaching due dates.

You can customize which widgets appear by clicking the **Customize Dashboard** button in the top-right corner of the Home screen.

## Quick Actions

The dashboard supports several keyboard shortcuts for faster navigation:

- **Ctrl + K** (or **Cmd + K** on Mac): Open the global search palette.
- **G then C**: Jump to the Courses section.
- **G then U**: Jump to Users & Teams.
- **G then R**: Jump to Reports.

## Search

The global search bar supports searching across courses, users, reports, and settings. Type at least three characters to see results grouped by category. You can filter results by type using the dropdown next to the search field.

For more detailed guidance on any specific section, refer to the relevant articles in this help center.

## Frequently Asked Questions

**Q: Can I customize which widgets appear on my dashboard?**

A: Yes. Click the **Customize Dashboard** button in the top-right corner of the Home screen to add, remove, or rearrange widgets. Your widget preferences are saved per user, so each admin can configure the layout that works best for them.

**Q: Are there keyboard shortcuts for navigating the dashboard?**

A: Yes. Evolve supports several keyboard shortcuts for faster navigation. Press **Ctrl + K** (or **Cmd + K** on Mac) to open the global search palette, or use sequences like **G then C** for Courses, **G then U** for Users & Teams, and **G then R** for Reports.

**Q: How do I reset my dashboard layout to the default?**

A: Navigate to the **Customize Dashboard** panel and click **Reset to Default** at the bottom. This restores the original widget arrangement and settings without affecting any of your data or platform configuration.

**Q: Can I access the admin dashboard from a mobile device?**

A: The Evolve admin dashboard is optimized for desktop browsers, but it is accessible on tablets and mobile devices through a responsive layout. Some advanced features like the course builder may have limited functionality on smaller screens. For the best experience, we recommend using a desktop or laptop.
