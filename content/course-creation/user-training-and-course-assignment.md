Once a course is completed and you are ready to start education, you need to assign it to users so they can begin learning. This guide covers course assignment, notifications, and how to track learner progress.

## Course Assignment

### Group assignment

1. Open the **Users** section in the left-hand panel.
2. Click **Assign course** in the top right corner.
3. In the pop-up window, select the desired unit (the group of users who should have the course assigned) or select **Assign to all**.
4. Select the desired courses in the **Available courses** dropdown.
5. Enable or disable **Send notification** in the form.

![Group course assignment dialog — select unit, status, and available courses](/images/training-group-assignment-dialog.png)

### Individual assignment

1. Open the **Users** section in the left-hand panel.
2. Set the checkbox next to the desired user.
3. Click **Assign a course** in the top right corner.
4. Select the course(s) to assign.

![Individual course assignment dialog — select courses for a specific user](/images/training-individual-assignment-dialog.png)

## How Will Users Know When They Are Assigned a Course?

Email notifications are sent only when a user is invited to a specific course. Make sure the **Send notification** checkbox is enabled when assigning.

If a user is simply added to the system without assigning a course, no email will be sent.

When a user is assigned to a course, the platform automatically sends an invitation to their email with a link to log in. After logging in, the user will see the course in the **Assigned** tab in the **My Courses** section and a notification on the **My Dashboard** page.

## How to See User Statistics

For course administrators, it is important to see who enrolled in a course, the current status of progress, and what results users show on knowledge tests.

### Statistics for a specific course

1. Navigate to the **Courses** section.
2. Choose the course in question.
3. Click the three dots in the top right corner of the course screen.
4. Select **Analytics**.

![Course menu — click the three dots and select Analytics](/images/training-course-menu-analytics.png)

On the opened page you will see the list of users passing the course and their progress:

![Course analytics page showing participant progress, grades, and completion status](/images/training-course-analytics-participants.png)

### Statistics across all courses

1. Navigate to the **Courses** section.
2. In the top right corner, click **Download report**.

![Top toolbar with the Download report button](/images/training-download-report-button.png)

An `.xlsx` file will be downloaded containing:

- Course name
- Course type
- Visibility type
- Type of term
- Deadline
- Course category
- User status statistics for all courses in your account

## How to Check Test Results

1. Navigate to the **Courses** section.
2. Choose the course in question.
3. Click the three dots in the top right corner of the course screen.
4. Select **Analytics**.
5. You will see the list of users passing the course and their progress.
6. Click the **eye icon** next to a user's name to see detailed information about their test results.
