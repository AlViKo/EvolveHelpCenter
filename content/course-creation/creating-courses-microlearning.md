Microlearning is a process of creating a course using artificial intelligence. The platform allows an administrator to upload materials and automatically generate a full training course in just a few minutes. Courses created through microlearning are designed for quick completion and rapid knowledge acquisition.

## 1. Starting Course Creation

To launch the microlearning process, open the course creation form and select the **Microlearning** mode.

![Select the Microlearning mode when creating a new AI course](/images/micro-mode-selection.png)

You can also access it by clicking **Create course** and selecting **Build with AI** from the dropdown menu.

![Build with AI option in the Create course dropdown](/images/micro-build-with-ai-menu.png)

### Uploading Materials

Upload up to two files with source materials for the course.

Supported formats: **PDF**, **Word (DOCX)**.

If the uploaded documents contain images, they will be automatically recognized and embedded in the course in the appropriate places.

> Excel files, video, and audio are not currently supported. Support for additional formats is planned in future updates.

### Filling in Course Parameters

After uploading files, fill in the following fields:

![Course creation form — title, description, file upload, language, color palette, and duration](/images/micro-form-top.png)

- **Course title** — a short and clear name (e.g., "Corporate Ethics").
- **Description / course goal** — what the course is for (e.g., "Learn the company's rules").
- **Course language** — the platform language is set by default. Can be changed to any supported language.
- **Color palette** — choose the palette for infographics and diagrams (e.g., your corporate colors).
- **Course duration** — choose one of the options: from 10 to 30 minutes.
- **Tone** — defines the style of content delivery (e.g., professional, friendly).
- **Target audience** — specify who the course is for (e.g., "New employees").
- **Desired structure** — optional. If you have preferences for the structure, specify them.

![Course form continued — tone of voice, target audience, desired structure, and Generate button](/images/micro-form-bottom.png)

## 2. Generating the Course Structure

After filling in all parameters, click **Generate Course Details** to start generation. The process consists of two stages:

### Stage 1: Structure Generation

The system analyzes the uploaded materials and forms the course structure — chapters and lessons. This stage takes several minutes. You can monitor the progress in real time.

![Generation in progress — analyzing the attached document](/images/micro-generation-step1.png)

![Generation in progress — filling the database with course details](/images/micro-generation-step2.png)

When the structure is ready, you will see a list of chapters, each containing lessons (theoretical blocks).

### Working with the Structure

![Generated course structure showing chapters and lessons](/images/micro-course-structure.png)

At this stage you can:

- View the generated chapters and lessons.
- Change the order of chapters and lessons by dragging them.
- Delete unnecessary chapters or individual lessons.
- Edit titles.

When you are satisfied with the structure, click **Confirm the structure** to proceed to the next stage.

### Stage 2: Generating Lesson Content

After confirming the structure, the sequential generation of each lesson's content will begin. Lessons are generated one by one.

![Lesson content being generated with progress bars](/images/micro-lessons-generating.png)

You can:

- Wait for the first completed lesson, open it, and start editing.
- Work with already completed lessons while the remaining ones are still being generated.
- Add new lessons or chapters manually at any time.

## 3. Editing and Enriching the Course

After all content has been generated, additional features are available.

### Introduction and Conclusion

Click the **Introduction and Conclusion** button. The system will create introductory and concluding sections based on all the generated content.

![Introduction and Conclusion button above the course structure](/images/micro-intro-conclusion-button.png)

### Infographics

For each lesson, you can generate infographics — diagrams and visual materials in your chosen color palette. To do this, go to editing a specific lesson by clicking the pencil icon.

![Buttons for adding audio and infographics to a lesson](/images/micro-add-infographics-button.png)

After clicking **Add infographics to the lesson**, you will see a notification that generation has started.

![Generating infographics loading indicator](/images/micro-infographics-loading.png)

The system creates several diagram options for each lesson. You can:

- Use all suggested options.
- Keep only the ones you like.
- Delete those that don't fit.
- Move infographics between content blocks using the arrows.

![Example of a generated infographic inside the lesson editor](/images/micro-infographic-example.png)

> Adding audio is not currently available. Support is planned in future updates.

### Editing Content

Inside each lesson, full editing is available: you can modify text, rearrange blocks, and add your own content. All these options are available using the new **Evolve Studio** editor.

## 4. Course Settings

In the separate **Settings** section on the course structure page, the following are available:

### Appearance

Upload a cover for the course, customize its appearance, and set the landing page background color.

![Course appearance settings — cover upload and background color selection](/images/micro-appearance-settings.png)

### Course Settings

Configure passing scores, deadlines, certificates, and availability options.

![Course settings — deadlines, passing score, certificates, and availability type](/images/micro-course-settings.png)

- Add skills to the course.
- Set passing score thresholds and deadlines.
- Choose availability type: by invitation, via link, to company users, or public.

## 5. Preview

The **Preview** button removes all control elements and shows the course as the end user (learner) will see it. The preview includes the title page and the course/lesson table of contents.

![Settings and Preview buttons in the top toolbar](/images/micro-settings-preview-buttons.png)

## Planned Improvements

The following are planned in upcoming updates:

- **Assessment task generation** — the system will automatically determine the type of tasks and populate the course structure.
- **Mascot generation** — the ability to create a virtual helper character for the course with a choice of style and color scheme.
- **Voiceover generation** — voice selection, listening to samples, and generating audio narration for the entire course or individual lessons.
- **Return to original request** — viewing the parameters with which the course was created.

> **Tip:** Microlearning is ideal for quickly creating short training courses from existing materials. For more extensive and detailed courses with advanced settings, use the "Long Read" process.
